# Monopoly Family (nama kerja)

Game board bergaya Monopoly untuk Android (Godot 4.x, GDScript) — clean, modern, family-friendly.
Proyek ini terpisah dari aplikasi TimeCraft di root repo.

**Buka di Godot:** Import → pilih `monopoly-family/project.godot` → tekan F5.

## Dokumen
