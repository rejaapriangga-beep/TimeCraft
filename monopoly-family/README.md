# Monopoly Family (nama kerja)

Game board bergaya Monopoly untuk Android (Godot 4.x, GDScript) — clean, modern, family-friendly.
Proyek ini terpisah dari aplikasi TimeCraft di root repo.

- `docs/TAHAP-1-DESAIN.md` — GDD, screen flow, UI hierarchy, arsitektur, scene & folder structure, data structure, roadmap MVP
- `data/board_classic.json` — data 32 tile board "Classic City"
- `data/config.json` — aturan angka (uang awal, bonus START, denda penjara, dll.)
